## Project Overview

A data-driven macroeconomic analysis project examining Abu Dhabi’s GDP and Consumer Price Index (CPI) trends between 2019–2024 using official datasets from the Statistics Centre – Abu Dhabi (SCAD).

### Key Objectives

• Analyze GDP growth trends and post-pandemic economic recovery patterns
• Evaluate inflation dynamics and CPI stability over time
• Identify macroeconomic indicators linked to diversification and economic resilience
• Interpret economic performance within the framework of Abu Dhabi Vision 2030

### Methodology

• Data collection and preprocessing using official macroeconomic datasets
• Trend analysis and comparative statistical evaluation
• Data visualization and interpretation of economic indicators
• Forecast-based analytical assessment and insight generation

### Deliverables

• Comprehensive 40-page analytical report
• GDP and CPI trend visualizations
• Economic interpretation and strategic insights
• Forecast observations and macroeconomic findings

### Skills & Tools

`Data Analytics` `Excel` `Data Visualization` `Statistical Analysis` `Trend Forecasting` `Macroeconomic Research` `Economic Data Interpretation`
